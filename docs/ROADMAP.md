# 开发路线

按优先级排。每条都可以单独开一个分支做。

## 已完成

- [x] 连接标签：彩色标签、左侧筛选、新建 / 改名 / 换色 / 删除
- [x] 标签页增强：拖拽排序、右键菜单、双击重命名、中键关闭、`Ctrl+Tab` / `Ctrl+1..9`
- [x] 命令快捷面板：常用命令保存、搜索、点击发送、仅粘贴模式
- [x] 命令历史：自动记录、搜索、重新执行、单条删除 / 清空，过滤不回显的输入
- [x] 下载管理器：队列（并发 2）、暂停 / 断点续传、取消重试、历史记录、同名文件去重、目录递归下载
- [x] 在线编辑：CodeMirror 6、语法高亮、原子保存、mtime 冲突检测、二进制 / 大文件拦截
- [x] 连接树右键菜单：连接 / 编辑 / 复制 / 删除
- [x] 批量命令：勾选多个已就绪会话，一条命令同时下发
- [x] 密码与私钥口令用 `safeStorage` 加密落盘
- [x] 文件多选：复选框 / Ctrl 点选 / Shift 连选，批量下载与删除
- [x] 配置同步：连接 / 标签 / 快捷命令打包，主密码加密，支持本地文件夹 / WebDAV / FTP / SFTP
